# Bloco-de-Notas

author: Luis Gustavo M. sousa / João Pedro Padilha

Esse Projeto refere-se a parte lógica codificada de um Bloco-de-Notas onde pode ser criado, buscado e deletado cada anotação, já criada.

---

## 📌 Índice

- Funcionalidades
    o sistema conta com salvamento, busca e exclusão de anotações, onde cada anotação é composta por um título, subtitulo, conteúdo e tags que o usuário pode escolher para ajudar em suas anotações.
- Tecnologias
    Kotlin e biliotecas do Java
- Estrutura do Projeto
    a estrutura do projeto conta com MVVM e ainda com o uso de repositorios em memória onde temos a manipulação de dados que teriamos com um banco de dados, isso simulando um em memória.

---

## 📖 Sobre

Explique de forma clara:

- O usuário pode criar suas anotações com título, subtítulo, conteúdo e tags, para organizar melhor suas ideias e informações. Ele pode buscar por suas anotações usando id de sua anotação, facilitando a localização de informações específicas. Além disso, o usuário tem a opção de deletar anotações que não são mais necessárias, mantendo seu espaço de trabalho organizado e eficiente.
- organização de ideias e informações
- O projeto foi criado para ajudar os usuários a manterem suas anotações organizadas e facilmente acessíveis, proporcionando uma experiência de usuário eficiente e intuitiva.
